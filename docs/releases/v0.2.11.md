# markdownview-- v0.2.11

本次更新重点修复 HTML 导出、标题导航和预览样式处理中的问题，提高阅读与导出的可靠性。

## 相比 v0.2.10 的改进

- **HTML 导出更安全**：对未能嵌入的本地图片路径进行转义，避免特殊文件名破坏导出 HTML 的注释边界。
- **本地图片导出更准确**：保留图片路径中的引号、连续空格和 HTML 实体字面量，减少可读取图片因路径解析变化而未能嵌入的问题。
- **链接跳转更准确**：仅把真正的页内锚点交给预览定位，带片段的外部地址继续按外部链接处理。
- **标题源码定位更稳妥**：遇到无法可靠核对的嵌套列表、引用或原始 HTML 结构时，仅在预览内导航，避免误跳到源码中的同名内容。
- **预览样式处理更稳定**：修复修改文本格式时可能导致遍历失效的问题，降低主题和字体样式更新时的崩溃风险。
- **回归覆盖与内部维护**：补充导出、链接、标题映射及样式处理的回归用例，整理重复状态和宿主适配接口。

## 下载、校验与安装

1. 下载本版本附件 `markdownviewdd-v0.2.11-windows-x64.zip` 和同名 `.zip.sha256` 文件。
2. 在 PowerShell 中运行以下命令，确认输出的 SHA256 摘要与校验文件一致：

   ```powershell
   Get-FileHash .\markdownviewdd-v0.2.11-windows-x64.zip -Algorithm SHA256
   Get-Content .\markdownviewdd-v0.2.11-windows-x64.zip.sha256
   ```

3. 关闭 notepad--，解压 ZIP，将 `plugin/markdownviewdd.dll` 复制到 `Notepad--.exe` 同级的 `plugin` 目录，替换旧版 DLL；如果仍有旧名称 `markdownview.dll`，请先移除。
4. 重启 notepad--，打开 Markdown 文件，按 `Ctrl+Shift+M` 显示预览。在“插件 → Markdown 预览 → 关于 Markdown 预览”中可查看版本信息。

ZIP 包含插件 DLL、README 和 LICENSE，使用宿主已有的 Qt 运行库。图片和完整指南可在[项目主页](https://github.com/jiy29104983/markdownviewdd#readme)查看。

## 兼容性

- notepad-- v3.8.3 插件版，Windows x64。
- Windows 10、Windows 11，或带桌面体验的 Windows Server 2016。
- 使用 notepad-- 自带的 Qt 5.15.2 运行库。
- 预览沿用 Qt Markdown 渲染，不支持 Mermaid、数学公式、JavaScript 和复杂网页样式。
- 标题源码导航仅在映射可靠且预览为最新快照时启用；复杂结构可继续使用预览内定位。
