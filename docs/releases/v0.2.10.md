## 下载、校验与安装

1. 下载本版本附件 `markdownviewdd-v0.2.10-windows-x64.zip` 和同名 `.zip.sha256` 文件。
2. 在 PowerShell 中运行以下命令，确认输出的 SHA256 摘要与校验文件一致：

   ```powershell
   Get-FileHash .\markdownviewdd-v0.2.10-windows-x64.zip -Algorithm SHA256
   Get-Content .\markdownviewdd-v0.2.10-windows-x64.zip.sha256
   ```

3. 关闭 notepad--，解压 ZIP，将 `plugin/markdownviewdd.dll` 复制到 `Notepad--.exe` 同级的 `plugin` 目录，替换旧版 DLL；如果仍有旧名称 `markdownview.dll`，请先移除。
4. 重启 notepad--，打开 Markdown 文件，按 `Ctrl+Shift+M` 显示预览。在“插件 → Markdown 预览 → 关于 Markdown 预览”中可查看新版本信息。

ZIP 包含插件 DLL、README 和 LICENSE，使用宿主已有的 Qt 运行库。图片和完整指南可在[项目主页](https://github.com/jiy29104983/markdownviewdd#readme)查看。

## 兼容性

- notepad-- v3.8.3 插件版，Windows x64。
- Windows 10、Windows 11，或带桌面体验的 Windows Server 2016。
- 使用 notepad-- 自带的 Qt 5.15.2 运行库。
- 预览沿用 Qt Markdown 渲染，不支持 Mermaid、数学公式、JavaScript 和复杂网页样式。
