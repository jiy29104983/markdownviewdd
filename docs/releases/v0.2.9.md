# markdownview-- v0.2.9

本版本围绕 Markdown 阅读与编辑协作，新增刷新模式、字体跟随、标题大纲、预览内搜索和代码块复制，并统一侧栏界面与插件菜单。

## 相比 v0.2.8 的改进

- **自动／手动刷新**：每个窗口独立选择刷新模式。手动模式保留展示快照，编辑及切换标签不自动全文渲染；可随时立即刷新。文件名、刷新模式、待刷新状态、性能保护和失败原因分别呈现，失败可重试或复制详情。
- **宿主字体与预览缩放**：打开预览时读取宿主已保存的 Markdown 正文字体与字号，六级标题按比例排版并体现层级缩进。原生 Ctrl＋滚轮缩放从当前显示字号开始，刷新、换标签和关闭／重开侧栏后保留；“重置预览缩放”可恢复当次宿主基准。
- **标题大纲与源码导航**：显示 H1～H6 标题树，可调整左右位置、显隐及宽度，支持键盘激活。最新预览在可靠核对源行后，可让源码和预览共同定位；旧快照仅在预览中跳转并提示刷新。当前章节标记不抢焦点，也不改变用户选中项或展开状态。
- **预览内搜索**：通过插件菜单、查找图标或预览内 Ctrl+F 搜索当前快照，支持字面匹配、区分大小写、命中计数、高亮和前后环绕。长文档分批搜索，修改查询不强制跳到首项；旧快照仍可查找，搜索不会自动刷新或改变导出的正文。
- **代码块阅读与复制**：每块代码显示语言标识和独立复制图标，支持键盘与右键菜单复制完整代码，保留缩进、Tab 和换行。视觉自动换行可关闭并跨重启记忆；复制按钮、语言装饰与提示不进入 HTML 导出。
- **统一侧栏界面**：精简标题栏和工具栏，提供明确的浮动／返回停靠入口、固定底部状态栏和可复制的错误详情。窄面板临时收起大纲，加宽后恢复选择；图标按目标 DPI 绘制，并修复暗色工具区配色。
- **整理插件菜单**：集中提供刷新模式、大纲显隐与左右位置、预览查找、同步滚动、重置预览缩放及导出，与面板操作共享状态并保持窗口隔离。
- **阅读位置与回归修复**：修复标题映射、搜索命中可见性、延迟排版覆盖用户滚动意图，以及首次滚轮缩放字号跳变。自动化覆盖扩展至八组 Qt 行为测试，并继续执行发布脚本隔离测试。

## 下载、校验与安装

1. 从本版本 Release 附件下载 `markdownviewdd-v0.2.9-windows-x64.zip` 和同名 `.zip.sha256` 文件。
2. 在 PowerShell 中执行以下命令，将输出与 `.sha256` 文件中的摘要比较，确认一致：

   ```powershell
   Get-FileHash .\markdownviewdd-v0.2.9-windows-x64.zip -Algorithm SHA256
   Get-Content .\markdownviewdd-v0.2.9-windows-x64.zip.sha256
   ```

3. 关闭 notepad--，解压 ZIP，将 `plugin/markdownviewdd.dll` 复制到 `Notepad--.exe` 同级的 `plugin` 目录；如果仍有旧名称 `markdownview.dll`，先移除旧文件。
4. 重启 notepad--，打开 Markdown 文件，通过“插件 → Markdown 预览 → 显示预览”或 `Ctrl+Shift+M` 打开侧栏。

ZIP 仅包含 `plugin/markdownviewdd.dll`、`README.md` 和 `LICENSE`，不附带 Qt 运行库。

## 兼容性与使用边界

- notepad-- v3.8.3 插件版，Windows x64。
- Windows 10、Windows 11，或带桌面体验的 Windows Server 2016；使用宿主自带的 Qt 5.15.2 运行库。
- 连续滚动同步仍按比例估算；大纲源码导航依赖可可靠核对的标题和宿主能力。
- 刷新模式、大纲布局及临时缩放按窗口保留，不跨重启保存；代码块换行偏好跨重启保存。
- 自动模式仍遵循 1 MiB 文件或 750 ms 完整渲染的性能保护。旧快照可阅读、查找与复制，双向连续同步等待刷新成功后恢复。
- 使用 Qt Markdown 渲染，不支持 Mermaid、数学公式、JavaScript 或复杂网页样式。
