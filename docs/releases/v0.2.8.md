# markdownview-- v0.2.8

本版本重点提升预览在多标签、多窗口和大文档场景下的稳定性、性能与可诊断性，并完善 HTML 导出能力。

## 相比 v0.2.7 的改进

- **标签与窗口状态更可靠**：改为由宿主标签和滚动事件驱动状态同步，切换标签时可更快跟随；每个 notepad-- 窗口使用独立控制器，避免多窗口之间的菜单、快捷键和预览状态互相干扰。
- **修复文档串页与过期预览**：严格跟踪编辑器身份、内容版本和文件路径。快速切换或关闭标签、后台批量替换、文件改名后，不会把旧文档内容恢复成当前预览。
- **大文档性能保护**：对 1 MiB 及以上文件或渲染耗时较长的文档暂停自动全文刷新，改为提示手工刷新；普通文档仍保持防抖实时预览。
- **限制预览缓存占用**：每个窗口最多保留 3 份原生预览，并按最近使用顺序回收；重新打开被回收的文档时会恢复其阅读位置。
- **滚动与阅读位置更稳定**：修复反向同步可能影响宿主滚动处理、主题变化或重新渲染后恢复旧位置、标签切换后丢失慢文档策略等问题。
- **HTML 导出增强**：始终导出当前活动 Markdown 文档的最新有效内容；即使预览侧栏隐藏也会按需刷新。相对路径和 `file:` 本地图片会嵌入为 data URL，导出的单个 HTML 文件更便于移动和分享。
- **链接与主题处理改进**：支持在预览中处理原生 Markdown 链接，并在文件路径或主题变化后刷新相关元数据和样式。
- **诊断日志更安全易用**：日志按 notepad-- 进程隔离，支持 1 MiB 上限和 3 份轮转文件；多窗口记录带独立标识，并减少完整本地路径暴露。
- **自动化回归覆盖扩展**：Windows 流水线新增 Qt 回归测试与 Release 发布脚本测试，覆盖预览生命周期、文档身份、多窗口隔离、日志和公开附件不可变策略。
- **Release 发布更稳健**：流水线重跑时会校验已有 ZIP 和 SHA256 内容；相同附件直接复用，缺失附件单独补传，发现同名但内容不同的附件则停止发布。

## 下载与安装

下载 `markdownviewdd-v0.2.8-windows-x64.zip`，校验同名 `.sha256` 文件后，将压缩包中的 `plugin/markdownviewdd.dll` 复制到 `Notepad--.exe` 同级的 `plugin` 目录。升级旧版本前请先关闭 notepad--。

## 兼容性

- notepad-- v3.8.3 插件版，x64
- Windows 10、Windows 11，或带桌面体验的 Windows Server 2016
- 使用宿主自带的 Qt 5.15.2 运行库

本版本已通过 GitHub Actions 的 Windows x64 Release 构建和自动化回归测试。真实 notepad-- 宿主中的加载、主题、多窗口及交互行为仍应按实际环境验证。
