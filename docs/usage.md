# 使用指南

[返回项目首页](../README.md)

## 打开预览

打开 Markdown 文件后，可以通过以下任一方式显示预览：

- “插件 → Markdown 预览 → 显示预览”。
- 快捷键 `Ctrl+Shift+M`，也可用它隐藏预览。
- 编辑器右键菜单中的“在侧边栏预览 Markdown”。

预览跟随当前 Markdown 标签页，支持 `.md`、`.markdown`、`.mdown`、`.mkd`、`.mkdn`、`.mdwn`。

## 自动与手动刷新

插件菜单和预览工具栏均可选择刷新模式，两处选择保持一致：

| 模式 | 使用体验 |
| --- | --- |
| 自动（默认） | 输入停顿后更新预览，切换标签时跟随当前文档 |
| 手动 | 保留该文档已有的预览，编辑和切换标签不会自动渲染；点击“立即刷新”取得最新内容 |

手动模式下，尚无预览的文档会提示先刷新。已有预览但源码发生变化时，状态栏会提示“待刷新”；此时仍可阅读、搜索和复制当前显示的内容。

磁盘文件达到 1 MiB，或最近一次完整渲染达到 750 ms 时，插件会暂停后续自动刷新。点击“立即刷新”可更新内容；若仍满足保护条件，后续自动刷新继续暂停。切换回自动模式不会绕过这一保护。

刷新失败时，可使用重试或错误详情中的复制功能。刷新模式按宿主窗口独立保留，切换标签、关闭再打开侧栏不会重置；重启编辑器后回到默认模式。

## 布局与同步滚动

预览可停靠在主窗口左侧或右侧。标题栏提供浮动、返回停靠和关闭按钮；关闭侧栏后可通过快捷键重新打开。

勾选“同步滚动”后，编辑区和预览区按各自滚动位置的比例联动。关闭同步后，两侧可以独立阅读。源码有未刷新修改时，双向同步暂停；刷新成功后恢复已勾选的同步滚动。

窄面板会简化工具栏文字并临时收起大纲，加宽后恢复所选布局。

## 标题大纲与章节导航

大纲展示 H1～H6 标题层级。通过插件菜单或工具栏“设置”，可以显示／隐藏大纲、将大纲放在正文左侧或右侧；拖动分隔条可调整宽度。

- 点击标题，或用方向键选择后按 `Enter`，可跳到对应章节。
- 预览已更新且标题能够可靠定位时，源码与预览一起跳转；这一操作不要求开启连续同步滚动。
- 源码有待刷新修改时，大纲仍属于当前显示的预览，跳转只移动预览并提示先刷新。
- 滚动预览时，大纲会标记当前章节，保留已有的键盘选择与展开状态。

大纲默认显示在左侧并全部展开。大纲布局设置保留在当前窗口内，不跨重启保存。

## 在预览中查找

通过“插件 → Markdown 预览 → 在预览中查找…”、工具栏查找图标，或在预览内按 `Ctrl+F` 打开搜索栏。编辑区的 `Ctrl+F` 仍使用编辑器自身的查找功能。

搜索按字面匹配，支持区分大小写、命中计数和临时高亮：

| 按键 | 操作 |
| --- | --- |
| `Enter` | 下一个匹配项，到末尾后从头继续 |
| `Shift+Enter` | 上一个匹配项，到开头后从末尾继续 |
| `Esc` | 关闭搜索栏并清除高亮 |

修改查询不会立即改变阅读位置；长文档搜索会分批计算并显示进度。搜索只针对当前显示的预览，不会触发全文刷新或源码跳转。手动模式下尚未刷新的修改不会出现在结果中；搜索高亮也不会进入导出的 HTML。

## 代码块阅读与复制

代码块左上角显示语言，右上角提供复制按钮。点击按钮即可复制完整代码，成功后短暂显示勾号。也可以按 `Tab` 将焦点移到按钮，再按空格激活，或在代码内右键选择完整块复制。

复制保留缩进、Tab 和换行。手动模式下复制的是当前预览中的代码；未显示在正文中的空围栏代码块可通过预览右键菜单复制。

“设置 → 代码块视觉自动换行”默认开启。关闭后保留长行，按需使用预览的水平滚动条。两种显示方式复制出的代码相同。换行偏好会跨重启保存，已经打开的其他窗口不会即时同步该设置。

## 字体与缩放

预览跟随 notepad-- 的明暗配色。每次打开预览时，插件读取编辑器已保存的 Markdown 正文字体和字号，六级标题按比例排版。保存新的字体设置后，需要关闭再打开预览，才会采用新的基准；读取失败时使用默认字体和 12 pt 字号。

在预览内按住 `Ctrl` 并滚动鼠标，可临时调整正文、标题与代码的字号。刷新、切换标签和关闭再打开侧栏后仍保留当前缩放；重启编辑器后恢复为 100%。插件菜单中的“重置预览缩放”可恢复本次打开时读取的基准字号。

预览缩放与编辑器缩放互不影响，也不会改写编辑器的字体设置。

## 图片与 HTML 导出

相对路径图片以 Markdown 文件所在目录为起点加载。与文档一起移动图片时，请保持相对目录结构。

选择“插件 → Markdown 预览 → 导出 HTML”后，插件会按需刷新**当前活动 Markdown 文档**，再将最新预览保存为 HTML。侧栏隐藏时也可导出，导出不会改变刷新模式或打开侧栏。

导出时的资源处理方式如下：

| 内容 | 处理方式 |
| --- | --- |
| 可读取的相对路径图片、`file:` 本地图片 | 嵌入为 data URL，可随 HTML 文件一起移动 |
| 远程图片 | 保留原地址，不主动下载；查看时仍取决于网络可用性 |
| 缺失、不可读或无法识别的本地图片 | 保留原引用，并在 HTML 注释中列出 |
| 普通超链接及其指向的本地文件 | 保留链接，不自动打包目标文件 |
| 搜索高亮、代码块复制按钮和语言标识装饰 | 不写入导出的正文 |

嵌入图片会增大 HTML 文件体积。取消保存不会写入文件。

## 渲染范围

预览使用 notepad-- 自带的 Qt Markdown 渲染，不支持 Mermaid、数学公式、JavaScript 和复杂网页样式。连续同步滚动按比例估算；无法可靠映射到源码的复杂标题只支持在预览内跳转。

版本适配范围见[宿主兼容性说明](host-compatibility.md)。如需报告问题，请在 [Issues](https://github.com/jiy29104983/markdownviewdd/issues) 中提供版本信息、复现步骤及最小示例。
